188SYSTEM_PROMPT: str = """\ 

189Convert the input statement into a CNF representation. 

190 

191The output JSON shape is enforced by the decoder — focus on producing the 

192right *content*. Conventions: 

193 

194- "entities": list every proper-noun constant the statement mentions 

195 (people, places, named objects). Constants are either uppercase-led 

196 (Tom, Whiskers) or lowercase tokens of >= 4 characters (penguin, 

197 tweety, felix). Leave the list empty for purely universal statements. 

198- "clauses": each clause is a disjunction of literals. A literal has a 

199 PascalCase "predicate", an "args" list, and a "negated" bool. 

200- "args" elements are either declared entities (as ground constants) or 

201 short lowercase variables (x, y, z) for universally quantified 

202 statements. Variables do NOT appear in "entities". 

203- Implications P -> Q become the clause (~P v Q). Biconditionals split 

204 into both directions. 

205- Existentials (exists x ...) are NOT supported; produce empty clauses 

206 if asked. 

207""" 

208 

209 

210def build_prompt( 

211 statement: str, 

212 examples: tuple[FewShotExample, ...] = EXAMPLES, 

213) -> str: 

214 """Assemble system prompt + in-context examples + the target statement.""" 

215 parts: list[str] = [SYSTEM_PROMPT, ""] 

216 for ex in examples: 

217 parts.append(f"Statement: {ex.statement}") 

218 parts.append(f"CNF: {ex.cnf_json}") 

219 parts.append("") 

220 parts.append(f"Statement: {statement}") 

221 parts.append("CNF:") 

222 return "\n".join(parts)
